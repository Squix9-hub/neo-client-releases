# Neo Client

Ein eigener Minecraft-Launcher mit Mods, Ressourcenpaketen, Skin-Wechsel und automatischen Updates.

## Download

1. Klicke rechts unter **Releases** auf die neueste Version (Latest).
2. Lade unter **Assets** die Datei `NeoClient-Setup-....exe` herunter und starte sie.
3. Falls Windows warnt ("Der Computer wurde durch Windows geschützt"), klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. Die Warnung kommt, weil das Programm nicht kostenpflichtig signiert ist.

Neue Versionen installiert der Launcher danach von selbst.
