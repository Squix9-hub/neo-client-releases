Neo Client

Dein eigener Minecraft-Launcher mit Mods, Skins und mehr

Für Windows herunterladen

Was der Launcher kann

Fabric und ModsMods direkt von Modrinth suchen, installieren, aktualisieren und ein- oder ausschalten.
Alle VersionenMinecraft in jeder Version, das passende Java holt sich der Launcher selbst.
Skin in 3DDein Skin als drehbare Figur, mit einem Klick änderbar.
Server beitretenServer speichern, Spielerzahl sehen und direkt beitreten.
RessourcenpaketePakete von Modrinth oder aus eigenen Dateien hinzufügen.
Dein AussehenFarben, Hintergrundbild und Größe frei einstellbar.
ScreenshotsAlle Bilder aus dem Spiel an einem Ort, zum Kopieren und Aufräumen.
Automatische UpdatesNeue Versionen installieren sich mit einem Klick.

So installierst du ihn

  1. Klicke oben auf Für Windows herunterladen.
  2. Starte die heruntergeladene Datei NeoClient-Setup.
  3. Melde dich im Launcher mit deinem Microsoft-Konto an (dort muss Minecraft Java Edition gekauft sein).
  4. Wähle eine Version und klicke auf Spielen. Beim ersten Start lädt der Launcher alles Nötige herunter, das dauert einige Minuten.
Windows-Warnung: Beim Start zeigt Windows eventuell "Der Computer wurde durch Windows geschützt". Das passiert bei allen Programmen ohne kostenpflichtiges Zertifikat. Klicke auf Weitere Informationen und dann auf Trotzdem ausführen. Auch dein Virenprogramm kann kurz nachfragen.
Neo Client ist ein privates Projekt und steht in keiner Verbindung zu Mojang oder Microsoft.
